# HCableAnalysis

## Introduction
**A Python framework for suspension bridge cable analysis.**

HCableAnalysis is developed by Structural Simulation Lab for suspension bridge cable modeling, shape finding, and finite element preprocessing. It provides an efficient workflow from parameter definition to numerical analysis.

---

## Features

- **Shape Finding** — Determine initial cable geometry under dead load.

- **Parametric Modeling** — Define cable parameters programmatically.

- **FEA Integration** — Export to ANSYS and Abaqus.

- **Benchmark Validation** — Verify against published solutions.

- **Excel Input** — Import geometry and loading data.

- **DXF Export** — Export geometry for CAD integration.
